# Study Agent — 本地学习助手

一个**离线优先**的个人学习助手：把课件与资料索引进本机的知识库，之后可以
**带出处**地提问、整理知识点、按遗忘曲线复习、记错题、写笔记。
资料留在你自己的电脑上，检索走本地模型，不上传、不花钱。

> ## 👋 第一次使用请先看这里
>
> 首次通过 `看板.cmd` 打开、且没有现有本机资料库时，程序会从项目 GitHub Release
> 下载约 **1.43 GiB** 的学习资料，校验 SHA-256 后导入 `.study_data/`；请保留足够磁盘空间。
> 如果已有本机库（包括已有学科目录而默认库尚不存在），会继续使用原有资料，下载过程
> 不会覆盖它。资料包含教材、课件、
> 预习和知识点；本项目不提供 API 密钥，使用模型功能时请在设置中填写自己的密钥。
> 资料种子不包含本地嵌入模型：向量检索需要另外安装模型，AI 功能还需自行配置密钥。
>
> 三步上手就在下面 —— [跳到「三步上手」](#三步上手)。

### Render 测试部署

Root Directory 留空，Build Command 设置为：

```bash
pip install -r requirements.txt && python tools/prepare_seed.py
```

Start Command 设置为：

```bash
python tools/start_with_seed.py --host 0.0.0.0 --port "$PORT" --no-open
```

资料首次准备时需下载约 1.43 GiB 并解压；运行空间与构建时间需实际验证。免费实例
无持久磁盘，休眠或重启后在线新增和修改的资料会丢失，基础快照会恢复。`KB_HOME`
可指定独立数据根，非空数据目录不会被种子资料覆盖。涉及公网访问、模型密钥及多人
修改前，请先确认服务端访问控制已启用；Linux 环境下旧版 Office 与 PowerPoint 整页
渲染仍受限制。完整线上功能还涉及依赖、模型、安全和持久化验证；未完成安全改造前
不要在公开服务中配置真实 API 密钥。现有资料与第三方材料各自的许可不因软件下载而改变。

## 这是什么

| 你能做的事 | 说明 |
|---|---|
| **入库** | 把 PDF / PPTX / DOCX / Markdown / 图片等资料解析、切块、建索引 |
| **问答** | 就整个知识库提问，回答**只依据你入库的资料**，每条结论都带出处（资料名 + 页码/幻灯片号），并可点开看原文片段 |
| **知识点** | 从一份课件里整理出结构化知识点（思维导图 + 末级知识点），另可提炼名词解释 |
| **复习** | 间隔重复：今日到期队列、掌握度打分、遗忘曲线月历 |
| **错题本** | 登记错题、按错因归类、与相关知识点联动 |
| **笔记** | 把结论回写成 markdown 文件；下次直接读回，抗上下文刷新 |
| **多学科** | 不同科目各用一套独立的库（资料、知识点、复习记录互不干扰） |
| **看板** | 上面这些都在浏览器里点，默认地址 `http://127.0.0.1:8756/`，只监听本机 |

三条设计取舍，先说清楚：

1. **离线优先**：嵌入（把文字变成向量）用的是随包下载的本地模型，检索不联网、不花钱。
2. **数据全在本机**：`raw/`（你的原始资料）、`index/`（索引库）、`notes/`（笔记）、
   `logs/`（产物与日志）都在程序目录里 —— 拷走就是备份，删掉就是清空。
3. **只有 AI 管线联网**：知识库问答、知识点总结、课件答疑，以及入库里的**两步**
   ——「AI 结构分析」与「整页识图」—— 会调用**你自己的**大模型接口，
   因而需要密钥、需要联网，**产生的费用由你自付**。这两步都能在看板里关掉，
   关掉后入库仍是完整的「解析 → 切块 → 本地嵌入」（详见[已知限制](#已知限制必读)）。

## 三步上手

### 第 1 步 · 安装（双击一次，约 5～15 分钟，取决于网速）

**双击程序目录里的 `install.cmd`**（中文名 `安装.cmd`，两个是同一个程序）。
它会依次：找 Python → 建独立环境 `venv/` → 装依赖 → 下载本地嵌入模型（约 100 MB）
→ 跑一遍自检。**可以重复运行**，已经装好的部分会跳过。

> 安装脚本默认就走**随包的国内 pip 镜像**（`pip.ini`）。若那个镜像在你的网络下
> 不可达，用 `install.cmd --no-mirror` 换回官方源；其它选项见 `install.cmd --help`。

想自己一步步来，也可以手工执行：

```powershell
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
venv\Scripts\python.exe -X utf8 tools\download_model.py   # 嵌入模型，约 100 MB，只需一次
venv\Scripts\python.exe -X utf8 tools\study.py check      # 自检：依赖 / 模型 / 数据库
```

自检最后一行是 `总体: 全部就绪` 就说明装好了。

### 第 2 步 · 填大模型密钥（要用 AI 功能才需要）

「AI 问答 / 知识点总结 / 课件答疑 / 入库的 AI 结构分析与整页识图」这几件事要一把
**DeepSeek API 密钥**（在 <https://platform.deepseek.com> 申请，费用由你自付）。
两种填法，任选一种：

| 方式 | 怎么做 | 生效时机 |
|---|---|---|
| **A. 看板设置窗口（推荐）** | 打开看板 → 右上角 **⚙ 设置** → 在「AI 问答」区填「API 密钥」→ 保存 | **立刻生效**，不用重启 |
| **B. `.env` 文件** | 把 `.env.example` 复制成 `.env`，把 `DEEPSEEK_API_KEY=sk-REPLACE_ME` 换成你的真密钥 | **需要重启看板** |

两条路都行，**优先级 A > B**。四（三）条管线默认共用这一把；想分账号计费，
可以在设置窗口里给每条管线单独填。

**不填也能用**：上传与浏览资料、入库（那两步会自动跳过）、本地检索、知识点与笔记、
错题与复习 —— 这些走本地模型与本地库，不需要密钥、不花钱。
只有问答与整理会提示「暂不可用」。

### 第 3 步 · 打开看板

**双击 `看板.cmd`**（ASCII 名 `dashboard.cmd`，两个是同一个程序）。
会弹出一个黑窗口并自动打开浏览器：<http://127.0.0.1:8756/>。

- **关掉黑窗口 = 停止看板**；看板不在时浏览器打不开是正常的。
- 端口被占用时它只提示并打开已有实例，不会重复启动。
- 想换端口：`venv\Scripts\python.exe -X utf8 tools\dashboard.py --port 8757`

## 放资料 · 入库

打开看板的「**资料**」页就能完成全部管理，不必敲命令：

| 操作 | 怎么做 |
|---|---|
| **加资料** | 选文件 →（可选）填子文件夹 → 「上传到 raw」→ 点「入库」 |
| **批量入库** | 把文件拷进程序目录下的 `raw\`，回页面点「刷新列表」→「入库全部待处理文件」 |
| **源文件改过** | 该文件会显示「内容有变」，点它的「重建」 |
| **不想让它被检索到** | 点「移除」——**只删索引、保留原文件**，随时可重新入库 |
| **彻底删除** | 点「删文件」——连磁盘文件一起删，需二次确认 |

两点值得知道：

- **上传不会自动入库**。你可以先确认文件放对了位置，再决定何时解析。
- **删除默认不删文件**：文件删了找不回来，索引随时能重建，所以「移除」才是常用操作。

### 入库做了什么（这决定了要等多久）

看板的「入库」与命令行的 `tools\study.py ingest` 走**同一条管线**，五步：

```
1. 提取文字（PDF 走版面感知；扫描页补 OCR，其中的表格按二维还原）
2. 切块（语义边界 + 标题面包屑 + 零丢弃契约）
3. AI 全局结构分析（让模型看完整份课件，画出思维导图、给每页定"节路径"）← 要密钥
4. 嵌入（本地 ONNX 模型，算 CPU，不联网、不花钱）
5. 整页识图（把每一页图片交给视觉模型理解）                        ← 要密钥
```

**第 3 步与第 5 步是仅有的两条花钱的路**，都能关掉：

| 开关（看板「设置 → 入库」） | `.env` 里的等价写法 | 代价 |
|---|---|---|
| 开启 AI 结构分析 | `OUTLINE_ANALYSIS=0` | 每份课件约 ¥0.01（46 页实测）；关掉后仍能检索，只是没有思维导图与节路径 |
| 开启识图 | `FIGURE_DESC=0` | **约 25 秒/页**，按页计费；78 页的课件要 30 分钟以上 |

**第一次试跑建议把两个开关都关掉**，先跑通「解析 → 切块 → 本地嵌入 → 检索」这条完全
不花钱的链路，再按需打开。

- **批量入库建议走命令行**：`venv\Scripts\python.exe -X utf8 tools\reimport_all.py`
  按资料逐份打印进度，中断可续。
- **重复入库不会重复花钱**：图片没变（哈希相同）就复用已有描述。

## 支持的文件格式

| 类型 | 后缀 |
|---|---|
| 文档 | `.pdf` `.docx` `.pptx` `.md` `.txt` `.rst` `.tex` |
| 数据 / 配置 | `.csv` `.json` `.yaml` `.yml` |
| 代码 | 常见源码后缀（`.py` `.js` `.java` `.c` `.cpp` 等） |

或者你手动「另存为」`.docx` / `.pptx` / `.xlsx`。

## 看板里有什么

顶栏从左到右：页码（问答 / 总览 / 复习 / 图谱 / 资料 / 知识点 / 错题 / 笔记）、
搜索框、学科切换器、**⚙ 设置**。

第一次打开默认落在「问答」页。空库时页面顶部会有[三步引导](#三步上手)。

| 页面 | 用途 |
|---|---|
| 问答 | 就你的资料提问，带出处角标；可限定只查某一份资料 |
| 总览 | 文档数、知识点数、今日待复习、未解决错题、笔记数，以及最薄弱的知识点 |
| 复习 | 今日到期队列 + 打分（掌握度）+ 遗忘曲线月历 |
| 图谱 | 知识点依赖关系图 |
| 资料 | 上传、入库、重建、移除、删文件；两个子页签分别对应教材与题库笔记 |
| 知识点 | 按课件看思维导图与末级知识点，可生成名词解释 |
| 错题 | 登记、按错因归类、批量删除 |
| 笔记 | 助手回写的笔记，可读回 |

### 右上角的「⚙ 设置」：四条管线各配各的

| 分区 | 里面能改什么 |
|---|---|
| 💬 AI 问答 | 模型、API Base、密钥、是否用图注作证据、推理开关与强度 |
| 🧩 AI 知识点总结 | 模型、密钥、推理档位、三份提示词真源 |
| 📥 入库 | 结构分析模型、识图模型、**识图总开关**、推理开关与强度、渲染 DPI |
| 🎓 课件答疑 | 每份课件的独立答疑：模型、独立密钥、是否用页图描述、上下文预算 |

三条要知道的：

- **保存即生效，不用重启看板**（设置写进程序目录下的 `config.local.json`）；
  但**正在跑的任务**用的是它启动时那份值，下一次任务才用新值。
- **密钥只存本机**：窗口里只显示后 4 位，留空提交＝不改动（不会把已有密钥清空）。
- **提示词是真源文件**：在窗口里改完保存会自动留 `.bak-时间戳`，并显示新旧 sha256。

## 数据在哪 · 备份与删除

所有东西都在程序目录里，没有隐藏位置、没有云同步：

```
study_agent/
  raw/            你的原始资料（只增不改）——**最该备份的就是它**
  index/study.db  索引库：切块 + 向量 + 知识点 + 复习记录 + 错题
  notes/          助手回写的笔记
  logs/           提示词真源、整理产物与日志
  models/         本地嵌入模型（可由 download_model.py 重新下载）
  .env            可选的环境配置（含密钥时请勿外传）
  config.local.json  看板设置窗口写的本机配置（含密钥时请勿外传）
```

- **备份**：拷走 `raw/` + `notes/`（+ 需要保留复习进度就带上 `index/`）。
- **换机器**：把整个目录拷过去，再在新机器上双击 `install.cmd` 重建 `venv`。
- **彻底清空**：关掉看板，删掉 `index/`、`notes/`、`logs/` 即可（`raw/` 是你的原件，删之前想清楚）。
- **`.env` 与 `config.local.json` 已在 `.gitignore` 里**，不会被提交到 git；
  但**分享整个目录前仍请手动确认这两个文件没有真实密钥**。

### 删掉资料后，以它为出处的记录会怎样

| 记录 | 删资料时如何处理 |
|---|---|
| 失去**全部**出处的知识点 | 自动清理 |
| 它下面的复习记录、依赖边 | 一并清理 |
| 仍有其他文档作出处的知识点 | 保留 |
| 手工创建、从未关联出处的知识点 | 保留 |
| 错题 / 笔记 | 保留，只解除对已消失知识点的引用 |

删除前会弹出**影响范围预览**；历史遗留的孤儿记录可以在「资料」页点
「清理无出处的记录」一键收拾。

## 已知限制（必读）

请在使用前读完这一节 —— 它们都是**如实说明**，不是可以绕过的提示：

1. **AI 功能需要联网。** 知识库问答、知识点总结、课件答疑，以及入库里的
   「AI 结构分析」「整页识图」，都要调用大模型接口。断网时这些步骤会失败或被跳过，
   但**解析、切块、本地嵌入、检索、复习、错题、笔记照常可用**。
2. **模型与密钥的费用由使用者自付。** 本程序不附带任何密钥，也不代付任何费用；
   费用产生在**你自己的**大模型账号上（按 token 计费，识图按页计费）。
   会花钱的只有三处：① 知识库问答；② 知识点总结；③ 入库里的两步
   ——「AI 结构分析」（约 ¥0.01/份）与「整页识图」（约 25 秒/页）。
   建议**先把 ③ 关掉**跑通链路，需要时再用小文件试算成本。
3. **PPTX 的整页渲染需要本机装了 Microsoft PowerPoint。**
   pptx 的整页图只能由本机 Office 的 COM 导出（这样字体、图层、SmartArt 才不走样）。
   没装 Office 时：**pptx 仍能入库与检索**，只是缺整页图；看板会明确告诉你原因，
   并给两条替代路径 —— ① 装上 Office 后重新入库；② 用 PowerPoint 把课件
   **另存为 PDF** 再入库（PDF 渲染走内置引擎，完全不需要 Office）。
   旧版 `.ppt` / `.doc` / `.xls` 的自动转换同样需要 Office。
4. **嵌入模型容量有限**：本地模型是 bge-small-zh（512 维，int8）。固定用例集
   Top-1 命中 9/10；语义跨度大的提问可能排不准，此时结果会带 `confidence: low`
   提示，建议改用 `docs --outline` 先定位章节。
5. **OCR 有误差**：公式中的括号、竖线容易识别错（例如 `P(B|A)` 可能被识别成 `P(BA)`）。
6. **检索是暴力余弦**：个人规模（几千块）毫秒级；十万块以上需要引入索引结构。
7. **切块不跨标题合并**：跨小节的长论述会被拆开，这是为保引用准确的刻意取舍。
8. **竖排文本、复杂表格、手写体**未做专门处理。
9. **只在 Windows 上验证过**；未在 macOS / Linux 上测试。

## 常见问题

**Q：双击 `看板.cmd` 一闪而过／报 “Python interpreter not found”。**
`venv` 没建好或没跟着目录一起拷过来。双击 `install.cmd` 重新安装；
这个窗口不会闪退，报错信息会留在窗口里。

**Q：浏览器打不开 `http://127.0.0.1:8756/`。**
看板是靠那个黑窗口活着的：窗口被关掉、或程序报错退出，地址就打不开。
先看黑窗口里最后几行写了什么。

**Q：端口 8756 被占用。**
多数是看板已经在跑了（脚本会提示并直接打开已有实例）。
要同时跑第二个实例：`venv\Scripts\python.exe -X utf8 tools\dashboard.py --port 8757`。

**Q：我没有密钥，能用吗？**
能。上传与浏览资料、本地检索、知识点与笔记、错题与复习都不需要密钥。
只有那四条 AI 管线会提示「暂不可用」，并告诉你去哪里填。

**Q：密钥会被提交或上传吗？**
不会。密钥只写在 `config.local.json` 或 `.env`（都在 `.gitignore` 里），
设置窗口只回显后 4 位，也不会出现在任何日志里。**唯一会外发的是你主动调用
AI 功能时发给大模型接口的那部分内容**（检索到的片段 + 你的问题）。

**Q：能把整个目录发给别人吗？**
程序本身可以（先删掉 `raw/`、`index/`、`notes/`、`logs/` 与两个配置文件，
就得到一个干净的空程序）。但**分发行为本身受[许可声明](#许可声明)约束**，
请先确认你已获得授权。

**Q：入库很慢 / 卡在某一步。**
最慢的是整页识图（约 25 秒/页），其次是 AI 结构分析。看板上有进度条与阶段提示；
想快就在「设置 → 入库」里关掉「开启识图」与「开启 AI 结构分析」，或先用小文件试跑。

**Q：想换嵌入模型 / 换大模型。**
嵌入模型路径由 `.env` 的 `EMBED_MODEL_DIR` 指定；大模型与密钥在设置窗口里改，
无需重启看板。`tools\download_model.py` 可重新下载默认嵌入模型。
