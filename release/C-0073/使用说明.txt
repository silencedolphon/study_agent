学习看板（Study Dashboard）—— Windows 版使用说明
==================================================

一、怎么用
----------
1. 把 StudyDashboard 整个文件夹解压到任意位置（例如 D:\StudyDashboard）。
   ★ 必须整个文件夹一起用：程序依赖同目录下的 _internal 子目录，
     只把 StudyDashboard.exe 单独拷出来是跑不起来的。
2. 双击 StudyDashboard.exe。
3. 会弹出一个黑色命令行窗口（那是程序本体，别关它），
   同时浏览器自动打开 http://127.0.0.1:8756/ 。
4. 用完了，关掉那个黑色窗口即可。

不需要安装 Python，不需要联网装依赖，不需要管理员权限。


二、你的数据放在哪
------------------
全部在 StudyDashboard.exe **同级目录**，第一次运行会自动生成：

    StudyDashboard\index\     学习数据库（study.db）
    StudyDashboard\logs\      运行日志、页面图、知识点产物
    StudyDashboard\notes\     笔记
    StudyDashboard\raw\       你放进去的资料（原始课件）
    StudyDashboard\subjects\  多学科（如果你建了别的学科）

备份就备份这些目录；整个文件夹拷到另一台 Windows 电脑上也能接着用。


三、AI 功能怎么配密钥
--------------------
本程序自身的功能（资料入库、检索、OCR、向量检索）**全部离线、不花钱**。
只有「AI 问答 / AI 知识点总结 / 课件答疑 / 识图」这几条要调大模型。

配法（二选一）：
  · 打开看板 → 右上角「⚙ 设置」→ 填对应管线的 API 密钥 → 保存。
    密钥只写在你自己机器上的 config.local.json 里，不会上传到任何地方。
  · 或者在 exe 同级目录放一个 .env 文本文件，写一行：
        DEEPSEEK_API_KEY=sk-你的密钥

不配也能用：入库、检索、复习、错题、OCR 都不受影响，
只是那几条 AI 管线会提示"没有找到密钥"。


四、提示词可以自己改
--------------------
首次运行后，exe 同级的 logs\knowledge\ 下会有 5 个 md 文件，
它们是「知识点总结 / 思维导图结构 / 名词解释」的**提示词真源**。
改完下一次任务就生效，不用重启（看板的「设置」窗口里也能直接看和改）。
改坏了想还原：把文件删掉，下次启动会自动从程序内置的那份恢复。


五、常见问题
------------
Q: 双击没反应 / 闪一下就没了？
A: 从命令行运行它，看报错信息；多半是端口被占用。
   可以指定别的端口：  StudyDashboard.exe --port 8899

Q: 浏览器没自动打开？
A: 自己访问 http://127.0.0.1:8756/ 即可。

Q: 杀毒软件报警？
A: PyInstaller 打的包常被误报，加白名单即可。

Q: 支持哪些系统？
A: Windows 10 / 11 64 位。不需要 Office——但「.ppt/.doc/.xls 老格式转换」
   和「pptx 整页图渲染」这两项依赖本机的 PowerShell + Office COM，
   没装 Office 时这两项会自动跳过并给出提示，其余功能不受影响。


六、目录里都有什么
------------------
    StudyDashboard.exe        主程序（看板服务）
    _internal\                程序内部文件（依赖库、模型、提示词、脚本）
    index\ logs\ notes\ raw\ subjects\   你的数据（首次运行后出现）
