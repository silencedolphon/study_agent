## 2. `.dsh/skills/study-agent/SKILL.md`（147 行）—— DSH 接入 A 面

frontmatter 的 `description` / `whenToUse` 决定**触发时机**：用户提到"入库 / 存资料 / 我的资料 / 我的笔记 / 复习 / 错题 / 知识点 / 学到哪了"，或需要基于本地已存资料作答并给出处时自动加载。

告诉 agent 的八件事：①**环境铁律**（必须用 `venv\Scripts\python.exe`，系统 python 是 2.7；统一 `-X utf8`）；②`raw\` 只增不改 + 支持/不支持格式；③**三层检索从省到贵**（`docs` / `docs --outline` 先看结构 → `search` 默认 hybrid → `--mode keyword` 精确 → `show --before/--after` 补上下文）；④**抗上下文刷新机制**＝有价值结论立即 `note save`；⑤复习与错题命令 + SM-2 评分语义 + 6 个固定错因标签；⑥四个典型工作流；⑦引用格式 `文档名 › 章节路径 › 页码/段号`（直接用返回的 `cite`）；⑧"检索不到就直说没有，禁止编造"。

## 7. 七条管线全解

### 7.1 入库管线（`raw/` → `study.db`）

**入口**：`tools/study.py ingest` / 看板 `/api/ingest` / `tools/reimport_all.py` → 都走 `core/ingest.py::ingest_paths()` → `ingest_file()`。

| # | 步骤 | 实现位置 | 产出 / 降级 |
|---:|---|---|---|
| 1 | 列文件 + 起进度 | `ingest.iter_files()`（rglob，排除 `~$`/`.`/`.part`） | `progress.begin()` |
| 2 | 类型路由 | `extract.detect_kind()` | `unknown`/`legacy` → `status="unsupported"`，**不落库** |
| 3 | **一页多张幻灯片切分**（前置） | `multippt.needs_split()` → `multippt.split()` | 生成 `xxx_slides.pdf` + `xxx.pages.tsv`，**此后全用切好的文件，原文件不入库**；异常静默回退 |
| 4 | 判重 | `db.sha256_file()` vs `documents.content_hash` | 相同且 `n_chunks>0` 且非 `--force` → `skipped`（**`n_chunks=0` 的失败记录不算，保证可重试**） |
| 5 | 文字提取 | `extract.extract()` → `extract_pdf/pptx/docx/image/text` | `ExtractResult.blocks` + `meta`（pages / body_font_size / scanned_pages / slides） |
| 6 | 扫描页 OCR | `extract.ocr_pdf_pages(path, scanned)`，dpi=100 | 追加 blocks；**OCR 抛错则 failed 且不落库**（避免被永久跳过） |
| 7 | 表格二维还原（在 OCR 内） | `tables.recover_pages(min_conf=0.4)` | 命中页 `kind="table"`、`group="tbl{pno}:{行首标签}"`；另出概览块；未命中退回一维 `kind="ocr"`。`OCR_TABLE=0` 一键回退 |
| 8 | 占位行 | `ingest._ensure_doc_row()`（只 INSERT 不覆盖） | 拿到 `doc_id`；`title=_title_of()` 择优 |
| 9 | **整页识图** | `figures.clear_document_figures()` → `figures.ingest_document_figures()` | `_adopt_previous_renders` → `render_pages` → `page_has_image` 过滤（仅 pptx）→ 按 `(doc_id,page,image_hash)` 命中 `figure_desc` 则**复用不计费** → 否则 `describe_page()`（`deepseek-flash`、`max_tokens=8192`，空输出且 <30 字用 **32,768 重试**）→ 写 `figure_desc` + `logs/figure_desc/<safe>/slide_XX.md` → 非"无知识性图示"页写 `chunks`（`source_ref="p.N 图"`、`ord=9000+page*10+…`）+ `embeddings` → 末尾清陈旧识图块。**异常只记 `fig_errors`，不中断入库** |
| 10 | AI 全局结构分析 | `outline.pages_from_result()` → `outline.analyze_deck()` | 命中 `logs/outline/<doc_id>.json`（`v==CACHE_VERSION=4` 且内容哈希一致）则复用；否则 `chat.chat_once`（thinking、32,768 tokens，空输出/JSON 截断 ×2 重试）→ **按数组顺序对页** → 续页继承上一页路径 → `_fill_duplicate_paths` 补末级。失败则 `outline=None` 降级 |
| 11 | 切块 | `chunk.chunk_blocks(blocks, doc_meta, outline)` | 每页起始 `_switch_to_outline`（**先 flush 再改面包屑**）；表格按 `group` 断块；超 1,100 走 `_emit_oversized`；`finish()` 后 `_merge_fragments` **四轮合并**；幻灯片下限 8 字 / 其他 80 字 |
| 12 | 嵌入 | `embed.get_embedder().embed_documents([f"{heading_path}\n{text}"…])` | **标题面包屑一起向量化**（只嵌正文时含答案块相似度仅 0.30，进不了前 5） |

### 7.2 检索管线（query → 证据）

`core/search.py::search(conn, query, top_k=8, doc_ids, max_per_doc=4, min_vec_score=0.35, mode="hybrid")`：

1. `use_fts = meta.fts5=="1"`；`pool = max(top_k*6, 40) = 40`
2. **向量路**：`embed_query()`（加 `QUERY_PREFIX`）→ 全量 `mat @ qv`（已 L2 归一化，点积即余弦）→ `argsort` → **绝对阈值** `s < 0.35` 即断 → **相对截断** `cutoff = max(0.35, top1*0.75)` → 取前 40
3. **关键词路**：FTS 侧（`bm25()` 归一化，短语 ≥3 字符、前 24 个）＋ LIKE 侧（2~4 字窗口 → **只留极大窗口**去真子串 → 前 16 → `text_norm` OR LIKE **不加 LIMIT**）→ IDF 权重 `log(1+total/df)` → 覆盖率门槛 ≥0.34 → **基准换成"实际可达最重词"** → 选择性门槛 ≥ 基准×0.75 → 相对截断 ×0.5
4. **关键词占优重排**：`max(kw) ≥ 0.9` 时把 strong 提到两路各自前部（**只重排不过滤**——过滤曾把正确答案整条丢掉）
5. **RRF 融合**：`1/(60+rank+1)`；strong 的关键词命中额外 `+1/(60+max(0,rank-5)+1)`
6. **候选裁剪**：`ordered[:max(top_k*3,20)] = 24`，再取元数据（**加权在取元数据之后，所以必须 ×3**）
7. **加权**：标题**只认叶子** `head.split(">")[-1]`（命中片段不得以虚词开头/结尾）→ `+0.004×min(ov,6)`；表格概览块 `+0.006`；表格行 `+0.005`
8. **排序 + 单文档配额**：按 rrf 降序 → 每 doc ≤4 → 截 8
9. **置信度**：`top.vec<0.50`，或 `<0.60 且 gap<0.03`，或 同文档且 `<0.55` → `confidence="low"`；"首位由关键词排定"/"结果集中同一文档"只作 `why` 附注**不降级**（避免告警疲劳，触发率 60%→10%）
10. **同主题续页扩展** `expand_continuations(max_extra=10)`（在置信度与配额**之后**）：按 `chunks.topic` + `_same_theme`（祖先/后代任意深度，或同父兄弟），门控 `vec≥0.55`（识图块 ≥0.70）或 `kw≥0.35`；候选=最近祖先 2 块→链后续，**轮询分配**名额；补入块 `is_extra=True`、`vec_score=0`

另有 `expand_neighbors(max_extra=6)`（**问答层专用**，两轮配额、允许跨一次主题、标注"相关性未验证"）、`get_chunk()`、`neighbors(before,after)`、`doc_outline()`。

### 7.3 问答管线（query → SSE 答案）

`core/chat.py::gather_evidence()`（SSE 实现在 `dashboard.py::api_chat_stream`，事件 `sources` → `delta` → `done`/`error`）：

1. **并发**：`ThreadPoolExecutor(max_workers=1)` 跑 `expand_query()`（模型抽 `terms≤8` + `queries≤3`，失败降级为空），**同时**主线程跑基础检索（**SQLite 连接不能跨线程**）
2. **共 7 次 `search`**：① 全库 `k=8` ② 课件组 `k=4`（`COALESCE(role,'courseware')<>'textbook'`）③ 教材组 `k=4` ④⑤ 改写式前 2 条 `k=4` ⑥⑦ 术语串分别 `keyword` 与 `hybrid` 各一次（累计 ≥12 条提前 break）；`picked` 为空再兜底全库一次
3. **配额**：按 `(-rrf, -vec_score)` 重排 → `_cap_evidence(max_total=10, per_kind_floor=2)`（**教材/课件各保底 2 条**，`is_extra` 不占名额）→ `expand_neighbors(max_extra=6)`
4. **组消息** `build_messages()`：证据分三组（`### 课件片段` / `### 教材片段` / `### 邻页参考（与问题是否相关未经验证）`）；识图块额外插 `〔以下是对插图的解读，含推断成分，非原文〕`；历史最多 8 条、每条截 1,500 字；无证据时明确写"没有检索到任何相关片段"。SYSTEM_PROMPT 四条铁律：只依据片段、必须标 `[n]`、没有就说没有、识图说明不得当原文引用
5. **流式**：`stream_chat()`（`deepseek-flash`、`max_tokens=2048`、`temperature=0.3`）逐行解析 `data: `，yield `delta` → `usage` → `done`

**出处标签的两个维度必须分清**：`documents.kind`（pdf/pptx）决定说"第 N 页"还是"第 N 张幻灯片"；`documents.role`（textbook/courseware）决定说"教材"还是"课件"（用错结论会反向）。
