# 学习看板 · 志愿者体验简报（2026-10-28）

> 你是本轮**新招募的志愿者**。请只用本简报 + 现场体验做判断，不要引用以前的评测结论或旧记忆。
> 你的任务是**像真实学生一样用一遍**这个本地学习看板，然后回答最后的几个问题。

## 0. 项目是什么

`study_agent` 是一个**完全本地运行**的学习看板（浏览器打开 `http://127.0.0.1:<你的端口>/`，无登录、无云端）。
它把老师发的课件/教材导入本机知识库，然后用外接 AI（DeepSeek）做结构化整理；所有资料、笔记、产物都在本机。

核心能力（都可在左侧导航看到）：

| 页签 | 能做什么 |
|---|---|
| 总览 | 文档/知识点/掌握度/今日复习等概况 |
| 资料 | 课件、教材入库与状态；能看到每份资料的页数/切块/AI 产物状态 |
| 知识点 | 课件思维导图；点任一末级节点弹出**知识点窗口**：总结、要点、原文出处、课件页图、笔记、**教材对应页/补充**、**AI 教材补充**（按需生成，先报价） |
| 复习 | **课件自测**（随机抽一半知识点，按结构路径回忆、标记已掌握/未掌握 → 熟悉度）→ **三步复习**（按导图逐个知识点 → 整份课件笔记 → 预习重点名词）；右下角有跨页签的**复习进度悬浮窗**；遗忘曲线月历可作为入口 |
| 预习 | 教材按章展开；每章可生成/查看**预习总结**（先细分小节，再给每小节的核心概念/老师会怎么讲/易卡点/自测）；先显示**费用预估**再确认 |
| 笔记 | 按“课件 → 绑定知识点”分组，可搜索、看全文、跳到知识点 |
| 问答 | 基于本地知识库的 RAG 问答，带出处（本轮**不要真的发问**，会产生 AI 费用） |
| 错题/搜索/设置 | 错题本、混合检索、设置中心（模型/提示词/管线开关等） |

## 2. 建议体验路线（约 30–40 分钟，按顺序即可）

1. **总览/资料（约 5 分钟）**：看首页数据；到资料页找一份课件，看它的页数、切块、产物状态，理解“导入 + 整理”大概是什么成本。
2. **知识点（约 8 分钟）**：知识点页 → 选一份课件思维导图 → 点一个末级节点：
   - 读总结/要点/原文出处/课件页图；
   - 看左侧导图栏、右侧教材页与教材补充（有就看看）；
   - 点“查看笔记”。
   评：这些内容比你自己翻 PPT 更省时间吗？可信吗？
3. **复习（约 8 分钟）**：复习页 → 选一份课件「开始自测」→ 按结构路径回忆，标记已掌握/未掌握 → 提交看熟悉度 → 进入三步复习（第一步会打开知识点窗口；第二/三步有笔记/名词窗口；每步可跳过）；注意右下角悬浮窗，切到问答再回来试试“继续”。
4. **预习（约 5 分钟）**：预习页 → 展开已生成的章（比如第6章），看小节内容；对未生成的章点“预习本章”**只看费用确认框然后取消**，别真的花钱。
5. **笔记/名词/搜索（约 4 分钟）**：笔记页看分组/搜索；知识点页的名词解释卡看“按预习重点名词重新整理（0 AI）”（可点，零成本）；顶部搜索试一个词。
6. **最后思考（约 5 分钟）**：如果老师刚发给你一份 PPT，你会不会花时间/钱把它导入这里？为什么？

## 4. 最后必须回答的问题（写进报告，尽量具体、可举例）

1. **你愿意长期使用这个看板吗？**（1–5 分 + 理由；什么条件下愿意/不愿意）
2. **这个看板帮助你解决了什么问题？**（哪些具体场景真的省了时间/提高了理解/发现了盲点；哪些没解决）
3. **这个看板是否比直接看教材、直接看课件更有用？**（分别比较：看教材 vs 看课件 vs 用看板；给出你的判断和理由）
4. **核心问题**：如果老师发下来一份课件，你为什么要花时间（和可能的几元钱）把它导入这个网站？
   这个看板相对“直接看书/直接看课件”的**不可替代优势**是什么？在什么情况下你愿意导入、什么情况下不愿意？
5. **成本/时间敏感度**：一份课件整理约 ¥0.3–2.8（历史真实值），一章预习约 ¥0.1–0.17；你愿意为“省下的时间/提高的复习效果”付这个钱吗？你更希望按什么方式计费/控制？
6. **最该保留 / 最该修 / 最想要的一个功能**（各一条）。
