## 2. 逐项修复

### A. 混合课件无文字图页（资料不丢）

**根因**：`ingest._page_pre_from_res` 只收集带提取块的页；`figures.extract_pages` 的 `pre_extracted` 复用分支提前返回，绕过 `fill_empty_pages`。混合课件中“只有图片、没有文字”的页没有上下文，识图规划会把它当 `ctx` 缺失跳过。

**修复**：

- `core/ingest.py::_page_pre_from_res` 按 `res.meta` 的 `page_count/slides/pages`（并取块最大页兜底）补齐 `1..N` 全页；无文字页写空 `title/body`，但保留实际 blocks（含 OCR）；
- `core/figures.py` 的 `extract_pages(pre_extracted=...)` 支持按页数信息补空页；
- 测试：3 页混合样本（页1文字+图片、页2仅图片、页3文字）→ pre 页集合 `[1,2,3]`，fake 识图规划/实际调用包含页 2；OCR 文本仍保留。

**边界**：真实 `C:\Users\Lenovo\Desktop\血管紧张素.pptx` 未重跑；本次只用 fake，不证明该文件全部化学结构识图准确。

### B. 教材 partial 覆盖旧完整总结 / 续跑（成果不丢）

**根因**：`_build` 对 partial 也写最终 JSON；partial 段的 `points` 被当作完成段，二次 build 跳过，导致“估算还要一次，但实际不再调用”；旧 done 文件被覆盖且无备份。

**修复**：

- **只有最终 `status=done` 才写最终 JSON**；
- partial 只写 `.pending.json`，保留旧 final 原样可读、可恢复；
- done 覆盖旧 final 前先版本化备份 `<stem>.json.bak-时间戳`，不删除旧成果；
- `_matching_parts` 只认完整段；`partial=True` 的段续跑重新调用；
- `estimate` / `read_summary` / 进度共用 `_resume_state`，新增 `calls_needed/resumable/complete_segments/partial_segments`；
- 兼容历史“partial 写在 final”的产物（有 parts 可复用完整段；无 parts 不误用）；
- `force=True` 与 `estimate(force=True)` 统一为全量重跑。

测试：`test_60` 9/9；旧 done + 新 partial 时旧 final 仍可读；二次 build 补齐后写 final 并备份旧 done；partial 段重跑、完整段跳过；旧产物无 parts 不误用。

### C. RunContext 凭据别名（账号/费用）

**根因**：`credential_ref` 直接存 `courseware_kp` 等细粒度名，而 `config.pipeline_key()` 主要认设置中心名 `kp/ingest/preview/...`；找不到时 `load_api_key()` 可能退回最近激活管线的密钥。

**修复**：

- `core/pipeline_runtime/context.py` 新增 `CREDENTIAL_ALIASES` 与 `canonical_credential_ref()`：
  - `courseware_kp / textbook_teach / terms → kp`
  - `ingest_vision / structures / ingest_outline → ingest`
  - `deck_chat → deck`
- `make_context.credential_ref` 存 canonical 设置中心名；`pipeline` 审计字段仍保留细粒度名；构建 context 时不读/activate 最近管线；
- `core/chat.py` 取 key 前再 canonical 一次，兼容旧 context；
- 测试：fake KP/PREVIEW 两把钥匙 + `pipeline_scope("preview")` 模拟最近预习 → 课件知识点非流式/流式请求均使用 KP 假钥，不使用 PREVIEW；ingest 三别名使用 INGEST 假钥。

### D. 硬超时 / 网关 504 / 锁 TTL / UI 状态

**修复**：

- `kp_build.ModelCallHang` 标 `remote_unknown=True / indeterminate=True`；不自动重发；`_v2_call` 只尝试 1 次；`calls[]`、`_v2_meta`、`progress_snapshot` 记录 unknown/indeterminate/status_detail；
- `figures._http_post`：HTTP **502/504** 视为远端未知，**只请求 1 次**；429/503 保留原有重试；测试 504 一次、503 两次；
- `SingleFlight`：
  - 锁文件增加 `heartbeat_at`；新增 `heartbeat(handle)` 原子续租；
  - 过期回收前检查持有者 PID 是否存活（Windows `OpenProcess+GetExitCodeProcess`，权限异常保守视为活）；
  - 活着/心跳未超时的 running 锁，TTL 和 `force` 都不抢；死且超期才回收；
  - 旧锁无 heartbeat 回退 created_at。
- UI：**未新增页面/按钮**；在现有 `50_knowledge.js` / `52_textbook_knowledge.js` 状态文案中增加 `partial`（部分完成）和 `remote_unknown`（结果未知，不会自动重发）提示；后端字段已可用。

测试：`test_61` 14/14；`test_39` 22/22（旧锁断言按“持有者死亡才可回收”的新语义修正原意）。

### E. 页图缓存缺页误报 / 选页

**根因**：`render_pages_cached(pages=None)` 只要有任意缓存页就设 `need=[]`；PPT COM 路径 glob 可能把目录旧 PNG 全返回。

**修复**：

- 新增只读 `_expected_page_numbers`（PDF 用 PyMuPDF 页数，PPTX 用 zip slide 数）；
- `render_pages_cached(pages=None)` 校验全量预期页；缺任意页时只补渲染缺失页，`cache_hit=False`；
- manifest 保留全部已知页；
- `render_pages(..., pages=[2])` 只返回请求页，glob 后过滤旧目录 PNG；
- 旧页图不删除。

测试：`test_59` 15/15 覆盖首次部分页、缺页补渲染、旧目录、fake COM 选页。

### F. data_revision 写路径

**修复**：在以下写路径的 **同一事务 commit 前** 补 bump：

- `figures._save_figure_row / _set_figure_chunks / _mark_no_info / _store_figure_chunks / clear_document_figures / _drop_stale_figure_chunks`；
- `ingest._rewrite_figure_chunks` 删除旧识图块；
- `dashboard.api_delete_doc` 删除资料（批量删除复用）。

写失败不提交即不 bump。测试：`no_info` 更新、删除资料后 revision 增加且 preview 章节缓存失效。

**边界**：仍需审计未来新增的分享导入/chunks 写入路径；真实库当前 revision 为 0，缓存尚未在真实库启用。

### G. 章节读取一致快照

**修复**：

- `textbook_kp._plan`：文档/章元数据 + 正文使用同一只读连接和 `BEGIN` 单事务快照；
- `preview.read_chapter_ch`：`locate → block 指纹 → 正文` 在同一只读连接/事务内；`list_chapters/locate_chapter/agg_block_ids/_read_chapter_ch_uncached/slow/read_text_pages_by_ids` 支持内部 `_conn=`（公共 API 兼容）；
- 不会返回 `ok=True` 的半章；不自动重试/追加付费。

测试：`test_60` 9/9，包含 WAL 代理模拟“两次查询之间重新入库”。

### H. outline token 上限

**根因**：`analyze_deck` 在 context 下把 cap=0 写成 32768；cap=1234 重试变 2468。

**修复**：

- cap>0：第一次/重试都保持用户 cap，不再翻倍；
- cap=0：context max_tokens=0，不发送 `max_tokens`，不再塞内部 32768；
- 无 RunContext 旧路径取 `config.token_cap("ingest_outline")`，同样不翻倍；
- 警告文案同步。

测试：`test_57` 更新为 6/6。
