# 学习看板使用手册

本手册适用于 `D:\study_agent` 中的学习看板。看板按学科管理资料、预习、知识点、复习记录和笔记；操作前先确认右上角显示的是目标学科。

## 1. 打开看板与选择学科

1. 双击项目目录下的 `看板.cmd`，在浏览器打开 `http://127.0.0.1:8757/`。
2. 点击右上角学科名称，切换到已有学科，或选择新建学科。各学科的资料和学习结果相互独立。
3. 页面内容未更新时刷新浏览器。长任务运行期间不要关闭看板进程；切换学科可能需要等当前任务结束。

## 2. 模型和费用

右上角“设置”中分别配置入库、AI 预习总结、AI 教材知识点和 AI 知识点总结。密钥留空时保留已保存的值。模型、推理强度和输出长度以各管线设置为准。

调用模型会产生费用。开始整理或预习前阅读页面的调用次数、费用与复用提示；实际费用取决于模型服务商价格以及实际输入、输出量。导入有效的分享包不需要重新调用模型。

## 3. 添加课件和教材

打开“资料”，可以粘贴本机文件路径或拖入文件。上传只是把文件放入资料目录；需要入库后才能参与检索和整理。

课件可以按单份或使用“批量选择文件入库”处理。“设置 → 入库 → 入库后自动整理课件知识点”开启时，确认后课件入库完成会继续整理知识点。入库过程若提示部分页面提取不完整，整理结果只基于可用材料，请对照原文件。

教材使用“资料 → 导入教材”入口，按章切块。入库时间与教材页数、文件质量和本机性能有关。完成后可在预习和教材知识点页面选择教材及章节。

## 4. 教材预习与教材知识点

1. 在“设置 → AI 预习总结”中确认“预习时同时整理教材知识点”已开启。
2. 打开“更多 → 预习”，选择教材和章节，点击“预习本章”，查看费用提示后确认。两个任务分别处理，进度和结果应分别核对。
3. 预习目录会分别显示每章的预习和教材总结状态。总结已完成时点击“查看教材总结”；未完成时查看具体提示。旧预习缺少总结时可点击“补齐教材总结”，确认费用后补跑。
4. 预习完成后阅读章概览、小节、难点、考点及自测题；教材知识点也可在“知识点 → 学习导图 → 教材”中选择同一本教材和同一章查看。难点与考点应对照教材原文核实。
5. 多章处理可在预习页点击“批量预习”，或在教材知识点页点击“批量整理”，勾选章节，先看估算再确认。批量任务按章处理，已有完整结果可复用。

如果只有预习结果，请检查预习联动开关、进度中的教材总结状态、错误提示和模型设置；可以使用“补齐教材总结”，也可在教材知识点页面单独重试。已经完成的旧预习不会因启用开关而自动付费补跑。原有预习仍可阅读；要使用更新后的难点和考点标准，需要确认费用后重新预习。

## 5. 课件知识点和复习

在“知识点”页点击“选择课件”，选择一份或多份课件并确认后整理。在“学习导图 → 课件”中选课件、展开节点、点击知识点查看内容和出处；可在窗口中使用已有的关联、笔记和答疑功能。课件可以加入复习日历，在“复习”页查看计划。

在“复习”页为课件点击“开始自测”或“重新自测”。自测页的课件导图可逐级展开，点击知识点打开总结窗口，不影响已经标记的答案。对于与考试无关的条目，可点击该题的“从自测排除”并确认；系统会尽量从该课件尚未抽中、也未排除的知识点里补充一条。可用候选不足时自测题数会减少。排除只影响该课件今后的自测，不删除原始总结；需要恢复时点击“恢复已排除知识点”。自测与补题在本地完成，不调用模型。

在课件知识点窗口中，可以手动选择对应的教材章节，以查看该章的预习难点、考点和教材重点名词。结果是否显示取决于对应章节是否已经完成相应整理。

## 6. 批量删除和题目管理

在“资料 → 本机文件”中勾选文件，点击“批量删除文件…”，可同时选择已入库和未入库文件。此操作永久删除原文件，已入库文件的索引和部分关联结果也会清理；教材按章预习、总结可能保留。若只想移除入库资料，可在“已入库资料”区选择对应入口，并在确认框中选择是否保留原文件。仔细阅读删除范围，永久删除无法撤销。

错题本支持勾选、全选和删除所选错题。知识点页中的独立知识点条目可多选删除；删除其关联复习记录和依赖关系，错题保留但会解除关联。课件导图中的总结目前支持按整份课件批量清除，不支持逐条批量删除。

在预习或教材知识点页面选择章节后，可打开“管理本章题目”，勾选并删除题目；删除前会备份章节结果。教材知识点的每个知识点至少保留一道回忆题。重新生成章节时可能产生新题目。

## 7. 分享包

在“资料 → 已入库资料”中找到课件或教材，通过该行的更多操作选择“导出分享包”。可按需选择是否包含原文件和页图；教材包可携带已入库的章节块、已有预习和教材知识点结果。

导入时切换至目标学科，打开“资料 → 导入分享包”，选择包并使用“一键导入当前学科”，或先查看包信息再导入。重复资料默认跳过；如需导入包中新增的结果，可查看包信息并选择另存一份。向量模型不兼容的包会拒绝导入，需使用兼容的库或重新处理。

## 8. 常见问题

- **看不到新按钮**：确认打开的是 8757 看板，刷新页面；如果看板尚未加载新版代码，需要在安全结束正在运行的任务后重启。
- **预习完成但没有教材总结**：先查看两个任务各自的结果及错误，再核对开关和模型设置；不要仅凭“已预习”判断总结已完成。
- **章节或结果为空**：检查是否选对学科、教材和章节，以及教材是否已按章入库。
- **任务失败**：记录页面显示的错误和章节，检查设置、模型服务及网络；已有部分结果可能支持续跑，重试前先看费用提示。
- **原文件或结果被删除**：永久删除可能无法从看板恢复。删除前先核对选择范围，并保留需要的原始资料及备份。
