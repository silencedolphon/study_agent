# 2026-10-19 新特性：知识点小窗左侧思维导图栏

- 需求：知识点页 → 课件思维导图 → 点节点打开「理解与要点」小窗后，在左侧显示本课件完整思维导图、
  高亮当前知识点；点左侧节点直接跳到对应知识点，不用关窗重找。
- 实现（`tools/dashboard.py` **+165 / −0 行，纯新增**）：
  - `mmRenderKp` 输出外包 `.mmkp-shell`（左 `<aside id="mmkp-tree">` + 右 `.mmkp-main`，原 `.ph/.pbody/.pf` 原样放入）；
  - `MMSIDE.cache` 按 docId 缓存 `/api/mindmap`（同 doc 只请求一次）；递归渲染完整树、叶子可点；
  - 当前知识点按 `d.kp_id` 高亮（左侧色条 + 底色 + 加粗）；点击复用 `mmOpenKp` 就地切换，不关窗；
  - 多知识点节点（`lkp_ids>1`）就地展开子项；
  - 响应式：≥900px 常驻 224px（小窗 `min(940px)`）；<900px 默认收起，头部「☰ 导图」抽屉展开
    （宽 `min(260px,82vw)`，390 无横向溢出、关闭按钮可点）；
  - 无产物/取不到数据：左侧一句人话并收起，右侧正文照常。
- 原有功能验证：上一/下一知识点、记入笔记/查看笔记、在资料库中检索、展开当页课件、Esc/点外关闭全部照常。
