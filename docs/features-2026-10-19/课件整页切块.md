# 2026-10-19 新特性：课件入库改整页切块

- 需求：课件入库不再让大模型做结构拆分；**每页课件切一块**；页内有图片（除文字层外检测到）→ 调/复用识图，
  识图信息与文字并入同一块；只有文字层的页 → 仅文字切块。
- 实现（只做分支，不改其它功能）：
  - `core/config.py`：新增 `INGEST_PAGE_CHUNK`（bool 默认 1，env `KB_INGEST_PAGE_CHUNK`），
    设置中心「入库」自动出现开关；
  - `core/ingest.py`：新增 `page_chunk_enabled()` / `build_page_chunks()` / `_first_heading()`；
    仅 `pdf/pptx` 非教材课件走新分支：每页一块、`source_ref="p.N"`（无区间）、有图页识图文字并入
    「【图片理解】」段、空页跳过、不跑 outline、不建 `p.N 图` 独立块、不调 `_rewrite_figure_chunks`；
    返回只增 `chunk_mode="page"`；旧模式（关闭开关）逐字回退原逻辑；
  - `core/figures.py`：`ingest_document_figures(..., store_chunks=True)` 可选参数，默认 True 旧行为不变；
    新模式下 `store_chunks=False` 只复用/生成识图文字，不建独立块；
  - 教材专线 / txt·md·docx·图片等非课件资料 / `core/chunk.py` 默认切块路径均未改动。
- 真实副本 0 成本对照（doc#40，26 页 / 16 有图页 / 10 无图页；figure 缓存 16/16 命中、硬禁 AI）：
  - 新模式：**26 块 = 页数**，全 `p.N`、0 区间、0 独立识图块、13 块含图片理解（16 命中 − 3 页无信息）、
    outline 0、`n_chunks=26`、4.67s；
  - 旧模式：21 文本块（15 单页 + 6 区间）+ **78 个 `p.N 图` 块**、38.36s；
  - 两边识图 `reused=16/described=0/cost=¥0/errors=[]`；真实主库只读、前后 sha256 一致。
- 测试：`test_15_page_chunk` 6/6；全量 `tests/run_all.py` **95/95、退出码 0**；`py_compile` 4 文件 OK。
- 风险/注意：
  1. PDF 无可靠「页有无图」判据（`page_has_image` 返回 None），仍按原口径全页送识图；pptx 才真正按形状过滤；
  2. 新模式下依赖 `p.N 图` 的统计/诊断脚本会看到 0（需求使然）；
  3. **旧数据不会自动重导**：要应用到已入库课件，需要用户确认后执行 backup → `reimport_all --force`。
