## 体验好的地方（举例）

1. **自测 → 熟悉度 → 三步，是真正能用的复习闭环（对我这种需要被推着走的人）**：随机抽 8/15 条，每条先给「├─ 结构路径 └─ 知识点名」，能按章节脉络回忆，不要求打字；提交后直接给「本次熟悉度 75%（已掌握 6 / 抽样 8）」和未掌握的两条名字。课件卡上之后一直显示「已自测 · 熟悉度 75%」，我下次回来知道从哪继续。这比我自己拿 PPT 从头翻强。
2. **知识点窗口的信息组织很扎实**：左树定位（第 3/37 条）、中间总结 + 要点 + 出处（p.5 · doc#41）、右侧教材对应（第9章 p.101–108）与「AI 教材补充」报价，还能上一/下一知识点连续看。**出处精确到页**让我愿意相信它，不是"AI 瞎编"。
3. **预习单节的质量超出预期**：不是简单摘要，而是「这一小节要解决什么 / 核心概念（6 条）/ 老师会怎么讲 / 易错点 / 自测 2 题（答案默认收起）/ 出处 / 本章关键名词 14 个（带"为什么重要"）」。第 6 章「毛果芸香碱」那页甚至把"缩瞳→虹膜根部变薄→前房角开大→房水回流↑→眼压↓"这条链讲清了，还把"降眼压不是减少房水生成"标成易错点——这是我想花 10 分钟在课前看的材料。
4. **费用是透明的、能刹车的**：预习先弹「预计 1 次调用｜成本上界 ≤¥0.0350｜章 4 页」；AI 教材补充先写「≤¥0.0554」；整理产物上标着历史花费（CNY 0.5027 / 0.7630）。我一路都在"确认"前点取消，没有被迫花钱。
5. **零成本的小工具很顺**：名词解释「按预习重点名词重新整理（0 AI）」点两下就把候选 14 个整理成 13 个；写笔记绑定知识点，保存即出现在笔记页（按课件→知识点分组、可搜索、有「复习这份课件的笔记」）。
6. **复习页的课件卡一眼能排优先级**：10 份课件按"未自测/已自测+熟悉度"标出，还带「18 条知识点 · 预习名词 14 个 · 第9章 镇静催眠药」——我不用打开每份也知道哪份最该先过。

## 卡住 / 失望 / 不信任的地方（举例）

1. **我做完自测+三步，总览完全没变**（最失望）：总览仍是「知识点 0 · 未学 0 · 已复习 0 · 今日待复习 0 · 今日已复习 0 次」，最薄弱知识点仍写「还没有复习记录。复习过一次之后，这里就会列出最需要补的知识点」。可我刚做完熟悉度 75% 的自测、还标了 2 条未掌握！**它没有告诉我"今天学了什么、弱在哪"**，我的努力在首页看不见。
2. **笔记页的「绑定知识点」名字会错位，而且两次进入不一样**：第一次进笔记页，「3胆碱受体激动剂」下列的是「毒蕈碱M受体激动剂/烟碱N受体激动剂/作用与用途」；我写了一条笔记、再进同一页，它变成「睡眠与镇静催眠作用/抗惊厥与抗癫痫/GABAA受体亚单位与结构」，而「外周神经药理学概论」下出现「发展简史/氟马西尼拮抗药」。查 API 发现知识点编号在不同课件里重复（`KP-N11-1` 同时用于 doc#48 与 doc#45，`KP-N05-1` 同时用于 doc#48 与 doc#43），前端把多份课件的 kp_id→名字塞进同一个全局表并互相覆盖（`viewNotes` 里 `Object.assign(kpNames, ...)`）。**这让我不敢相信"按知识点复习笔记"这个入口。**
3. **知识点页首屏还是"批量整理"最显眼；名词解释默认选的课件与当前无关**：进知识点页，第一张大卡是「批量整理知识点」，名词解释默认选「1中枢神经系统药理学概论 · 暂无名词解释」，并提示"该教材章节还没有预习总结（第12章）"——我差点以为名词解释坏了，直到自己选「镇静催眠抗焦虑药」才发现有 14 个预习名词。**默认值应该跟着"我最近在看的课件"走。**
4. **熟悉度 75% 之后，我找不到"这 2 条未掌握"的清单**：未掌握名字只在提交结果那一刻出现；之后复习页只剩「熟悉度 75%」和「继续复习」，要重新进三步流程才可能看到标红。**缺少"薄弱点清单/今日任务"这个我第二想看的页面。**
5. **自测/三步不会自动排复习计划**：月历仍然是空的（10/28 显示「这一天没有安排复习」），提示我要去「知识点 → 录入遗忘曲线」才有 5 轮复习日。也就是说：**我今天自测了，但明天没有任何提醒**——复习闭环缺了"排期"这一环。
6. **教材补充的"旧版/需补做"状态很绕**：「3胆碱受体激动剂」的知识点窗口里，教材补充一栏只写「教材已入库，可到导图栏补做教材补充 / 去导图栏补做」；到导图栏又出现「重新 AI 定位并补做（≤¥0.0172）」。我想看教材原文对照，还得先做一次付费映射——对"现在就要复习"的场景太绕。
7. **细节文案有一次让我以为坏了**：首次点开名词解释时展示的是"暂无名词解释"（默认课件无数据），而不是"请选一份课件"。另外知识点页/预习页加载都有 4–6 秒空窗（只有"加载中…"），预习页一屏 4355 字、548 个节点，稍显压。

## 三个问题的回答（1–5 分 + 理由）

**Q1 你愿意长期使用这个看板吗？—— 4 / 5**
愿意。理由：它是**唯一一个让我"一章 10 分钟先过一遍再回去看课件"和"自测出具体不会的条目"的工具**，而且费用透明。扣 1 分是：总览不汇总学习成果、笔记分组会错位、部分功能要先付费补做教材映射才完整；我把它当成"二轮复习+课前预习"的工具，而不是每天第一个打开的 app。愿意长期用的条件：① 自测结果能进总览/薄弱点清单；② 笔记分组稳定；③ 单科成本可预期（≤¥10）。

**Q2 这个看板帮助你解决了什么问题？**
- 解决（真实省时间/提高理解）：① 课件 46 页先看知识点窗口，比翻 PPT 快很多（我先看「药物分类」那条，30 秒拿到三类划分和"硫喷妥是例外"这个考点）；② 自测发现了盲点：抽 8 条里 2 条不会（代谢与临床应用、毒蕈碱M受体激动剂），有名字可追；③ 预习单节把"老师会怎么讲、易错点、自测题"都给了，课前 10 分钟就能进入状态；④ 名词解释 0 AI 整理，省了查词时间；⑤ 出处精确到页，检索/对照可靠。
- 没解决：**跨天复习计划**（自测不排期、月历空）；**薄弱点汇总**（未掌握清单只出现一次）；**学习成果统计**（总览全是 0）；**跨课件笔记按知识点回看**（分组错位）。

**Q3 这个看板是否比直接看教材、直接看课件更有用？—— 部分场景 4 / 5，整体"不是替代而是第二层"**
- 看课件 vs 看板：看板**更省时间**（定位、自测、出处），但**不如课件完整**（图、表格、动画在课件里；看板的知识点窗口只有文字与要点，我看到的教材页图缩略图是空的/未加载）。→ 第一次学看课件，第二遍复习用看板。
- 看教材 vs 看板：看板预习摘要（小节级）比啃 42 章正文**快一个数量级**，适合课前/考前；但只有 4 章已有预习，其余 38 章要逐章付费生成；教材里的细节、例题、图表还得回书。→ 看板是"先看骨架"，教材是"补细节"。
- 结论：**看板是"复习索引层 + 课前速览层"，不是教材/课件的替代品。** 我用它的正确姿势是：课后再打开看板，按知识点过一遍 + 自测，然后回课件/教材查细节。

## 核心问题：为什么要把老师课件导入？相对直接看书/课件的不可替代优势是什么？

**不可替代的优势（只有导入才能做到的）：**
1. **把"老师的考点口径"变成可检索、可出处的结构化条目**：考试是老师出题，PPT 的结构就是考试结构。导入后我可以搜「地西泮 作用机制」直接跳到 p.15 的 GABAA 受体结构图条款，而不是在 46 页里翻。**这是任何通用教材/网课都替代不了的：只有我老师这份课件，才带着我这次考试的答案。**
2. **把一份课件切成 15–56 条末级知识点，可自测、可量化熟悉度**：直接看 PPT 我只会"看完了，好像会了"；自测抽一半、标记掌握/未掌握，得到 75% 这样的数字和两条具体不会的名字。**这是"看完"和"会了"之间的桥**。
3. **课件与教材的章级映射**：第9章 镇静催眠药 → 教材 p.101–108，预习按小节给"老师会怎么讲/易错点"。直接翻书要自己对照章节目录，这里已经对好了（虽然要花一次 ¥0.0047 映射 + AI 补充可选）。
4. **笔记绑定知识点，期末可以按"我记过笔记的条目"回看**：纸质笔记做不到按课件+知识点索引；微信收藏更做不到。

**什么情况下我愿意花时间（和 ¥0.3–1.8/份）导入：**
- 老师刚发、明确是考试范围、页数多（≥30 页）的课件——一次导入，后面两周反复用；
- 我需要"被抽背+量化弱项"的时候（保研边缘，绩点差一点，需要确认自己真的会了）；
- 老师 PPT 是考点口径（不是复制教材）。

**什么情况下不愿意：**
- 一次性/水课/不考的内容；课件质量差（只是截图教材）；
- 我只剩 2 天复习：直接背课件更快，没时间等整理、也没钱试错；
- 无法确定费用/效果时（我不想为"可能没用"付钱）。

**一句话**：导入的价值 = **把"老师的 PPT"变成"能自测、能定位、能按知识点复盘的题库"**。只有当我确定要在这份课件上花两周以上时，这个转换才回本。

- 整理：历史 ¥0.32–1.83/份（本次沙箱 0.5027 / 0.7630），我**愿意**为考试范围的课件付这个钱（相当于一杯奶茶换两周复习效率），但希望：① 先让我看一份免费样例/预览；② 一次批量导入给总价上限，别一份份确认；③ 失败重试不重复计费。

- **最该保留**：**课件自测 → 熟悉度 → 三步复习 + 右下角悬浮进度窗**。它把"我到底会不会"变成了一个可执行、可量化、可中断续做的流程，是我这次体验里最不可替代的东西。

## 总体结论（是否推荐给同学、适合谁）

- **会推荐给同学，但有筛选**：推荐给"老师发 PPT 型课程 + 期末要背 + 愿意花几元钱和一点等待"的人；特别是**像我这样需要被抽背、需要知道弱项具体在哪、又想省翻阅时间**的保研/考研边缘学生。
