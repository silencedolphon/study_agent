3. 文字层级：这是"文字墙"的直接解药

看板现在只有 --fg / --dim 两级。所有说明文字共用同一个灰， 于是"要么全都很显眼，要么全都很淡"——文字墙就是这么来的。 不是把字删光就好了，是让留下的字有层次。

现状：2 级
--fg #e6e9ef
要点正文与标题
--dim #9aa3b2
说明文字、时间戳、空态、出处、提示 —— 全挤在这一级
linear-app：4 级
--fg #f7f8f8
标题 / 关键数字
--fg-2 #d0d6e0
正文：要点、段落
--muted #8a8f98
说明：图中这些解释性文字
--meta #62666d
时间戳 / 路径 / 禁用态 / 计数

⚠ 落地要点（本项目硬约束）：linear 的字体栈是 Inter，而看板界面是中文，Inter 不含中文字形； 本项目"外部 CDN 引用 0"，不能引 Google Fonts。做法：保留 Inter 段但必然回落，中文交给系统栈 —— --font: "Inter", -apple-system, "Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif， 不下载任何字体文件。看板现状（6200 行）本来就是这个栈，属于零成本沿用。

5. 建议直接贴进 :root 的 token 块

位置：tools\dashboard.py:6193-6197。由卡① 独占修改，其余卡等它。

:root{
  /* 底色（linear-app，深色原生；panel2 补一级台阶） */
  --bg:#08090a; --panel:#191a1b; --panel2:#212223;
  --line:rgba(255,255,255,.08); --line-soft:rgba(255,255,255,.05);
  /* 文字四级（新增 fg-2 与 meta 两级）★ 本次改造的关键 */
  --fg:#f7f8f8; --fg2:#d0d6e0; --dim:#8a8f98; --meta:#62666d;
  /* 主张色（靛紫，全站唯一彩色，只给主 CTA） */
  --accent:#5e6ad2; --accent-on:#fff; --accent-hover:#828fff;
  /* 状态色：沿用看板现值（回归风险低优先） */
  --ok:#3fb950; --warn:#d29922; --bad:#f85149;
  /* 圆角分级 */
  --radius-sm:6px; --radius:8px; --radius-lg:12px;
  /* 间距与字号（只取小端） */
  --sp2:8px; --sp3:12px; --sp4:16px; --sp6:24px;
  --fs-xs:12px; --fs-sm:13px; --fs:14px; --fs-lg:16px;
  --focus-ring:0 0 0 2px rgba(94,106,210,.42);
  /* 中文交给系统栈：本项目外部 CDN 引用为 0，不下载字体 */
  --font:"Inter",-apple-system,BlinkMacSystemFont,"Segoe UI",
         "Microsoft YaHei","PingFang SC",sans-serif;
}
迁移风险提示：看板现有组件全部依赖这 9 个变量名（--bg/--panel/--panel2/--line/--fg/--dim/--accent/--ok/--warn/--bad/--radius）。 上面这块保留了全部旧变量名，只改取值 + 新增 6 个变量 —— 所以组件代码一行都不用动就会跟着变。 这正是把"设计 token 落地"单独拆成卡① 且最先做的原因：它风险最低、收益最广。
