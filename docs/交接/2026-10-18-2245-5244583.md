## 4. 关键决策与理由
- **一个产品 + 三个场景预设（A 日常 / B 备考 / C 冲刺），不做三套版本**：需求 75–80% 共用；单人+AI 资源下，三套版本会让修复/验收/发布成本 ×3，且代码易漂移。只在未来对外分发时用 `release_pack` 预设生成不同安装包。
- **先修"写入闭环"再深修检索**：学生反馈里"不能建卡/不能记错题"是走不通的根因；检索排序问题先做规则级修复（可控、零成本），`search.py` 彻底重建（LLM 反编译约 ¥0.3 + 人工）单独申请。
- **评测/开发一律用隔离实例**：真实数据只读；任何写操作只在 `_work/eval/instances/*/sandbox` 或 `tests` 沙箱。
- **不整体回退恢复源**：11 个文件比恢复源新，覆盖会丢功能（见审计 §2.3）。
