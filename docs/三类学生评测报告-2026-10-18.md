## 1. 结论摘要（先看这 10 条）

1. **三类学生给出的总评都不高，但原因不同**：学霸 5/10（只肯当"检索/出处核对工具"）、保研边缘 3/10（"帮不了我保研"）、突击 4/10（"只能当第二工具"）。
2. **全站最强功能是 AI 问答**：三次评测共 8 次真实提问，**0 幻觉、全部带编号出处、找不到会直说**，耗时 3.5–8.0 秒；三个角色都把它列为"最帮我的功能"第 1 名。
3. **最大的产品硬伤是"写入闭环断裂"**：知识点页**没有新建入口**（前卡 C-0053 主动删除了前端入口，注释仍在）、`POST /api/mistake` **404**（错题只能看/删不能记）、笔记空态指向的【记入笔记】按钮在知识点详情里**不存在**。
4. **更根本的架构断层（Lead 交叉验证）**：AI"整理知识点"只写 `logs/knowledge/*.json` 产物，**不写数据库**；而知识点列表/复习队列只读数据库。结果：真实站点 7 份课件已有整理产物，数据库里知识点却还是 **0 条**——"整理完看不见、复习队列永远空"。
5. **检索召回/排序不可信（三份报告一致命中）**：统一问题"镇静催眠药按化学结构分几类"AI 回答"资料里没有"，但课件 p.5《镇静催眠药分类》确实存在；搜"苯二氮卓类 作用机制" top1 是**巴比妥类**。这与源码审计的已知缺口吻合：`core/search.py` 是 AI 重建版（v1.1 真值 32 函数缺 13 个，`expand_neighbors` 49 行 vs 真值 195 行）。
6. **掌握度显示 bug（Lead 复现）**：同一知识点，`/api/kps`、`/api/graph` 返回 `mastery=0.0`，而 `/api/kp`、`/api/stats` 返回 11%~32% → 列表全 0%、图谱全红、排序失效、同屏 toast "13%" 与列表 "0%" 打架。
7. **新用户首屏没有"下一步"**：总览 5 张卡全是 0、互指成环（总览→复习→知识点→批量整理），没有 CTA；空状态文案大量指向不存在的按钮/入口。
8. **排版/移动端问题集中**：资料页首屏 3420 字全是导入说明、已入库列表要到 y≈2364px 才出现；**手机 390 宽资料页横向溢出 2.03 倍**（788 vs 390）；卡片标题 13px 小于正文 14px（层级倒挂）；Markdown 表格渲染成裸管道符；无浅色主题。
9. **三类学生真正缺的东西不同**：学霸要"写入→调度→导出"闭环（对标 Anki/Notion）；保研边缘要**目标/倒计时/短板/进步趋势**；突击生要**考前冲刺模式 + 手机可用**。现在这三类能力都不存在。
10. **好消息**：数据结构与本地能力底子不错（出处精确到页、SM-2 是真调度、大纲/上下文好用、AI 纪律好）；上述问题**多数是入口/展示/接线层问题，不是重写**。按本报告 P0 修完，三个角色的评价预计可提升到 7/10 左右。

## 3. 三方结论速览

### P1 学霸 —— 5/10，"可以当检索器，不能当学习系统"

- **能帮他**：找原文/核对出处（60–90 秒 vs 翻 PPT 3–5 分钟）、扫大纲、问机制看页码。
- **致命缺口**：不能建卡（UI 无入口）、不能记错题、笔记按钮不存在、掌握度永远 0%、知识点/复习历史不能导出 → **写入→调度→导出**闭环缺失。
- **对 Anki 的对照**：建卡 Anki 30 秒 vs 本站在无入口；每天刷 20 张卡 Anki 键盘 10 分钟 vs 本站 3 点击/条且无快捷键。
- 他最看重的三个亮点：大纲模态（42 章节页码直达）、AI 出处角标可点开原文、真 SM-2（1→6→×ease，0–2 重置）。

### P2 保研边缘 —— 3/10，"现在帮不了我保研"

- **能帮他**：课件检索、带出处答疑、看哪个知识点分最低、按课件排复习日历。
- **不能帮他**：知道"保研线差多少分"、建自己的知识清单、记录复盘错题、看见"这周比上周强"。
- 最劝退："我 3 步内就被劝退了"——总览→复习→知识点→批量整理报"没有可整理的课件（先入库课件）"，而资料明明已入库；
  错题本永远空且空态指向不存在入口；同一知识点 0%/11%/13% 三处不一致，月历显示"已完成 undefined"。
- 情绪影响：对每天算分的人，收益（查资料）远小于困惑（三个 0%、死路空态）。

### P3 考前突击 —— 4/10，"只能当临时抱佛脚的第二工具"

- **能帮他**：问一句 5.8 秒出带 17 个出处角标的答案、核对 PPT 原话；自己硬问出的"只剩 2 小时背哪些"清单确实可用（7.4s/约 2100 字/含 40-40-40 分钟分配）。
- **不能帮他**：全站"速成/冲刺/必背/一页纸/倒计时"关键词 **0 命中**；答案太长（1715–2100 字）且自动滚到结尾；手机 390 宽资料页横向溢出 2.03 倍；复习闭环进不去。
- 最劝退：没有速成入口、空态指错路、**检索会把药名答错**（"苯二氮卓" top1 是"巴比妥"）——突击生最怕"分不清对错"。

## 4. 交叉验证后的核心问题（按严重度）

> 以下每条都有角色证据 + Lead 独立复核；括号内为证据位置。

### P0-A 知识点/错题/笔记的"写入闭环"断裂（三方共识 + Lead 代码复核）

| 事实 | 证据 |
|---|---|
| 知识点页无"新建"入口；`kpForm()` 仍在但**全仓无渲染调用**；代码注释明说"删的只是页签上的入口"（卡 C-0053） | `dashboard.py:3117-3118`；P1/P2/P3 三份报告 J5 |
| 后端 `POST /api/kp` 可用（Lead 实测 200），但学生只能靠 API/命令行 | Lead p2 实例实测 |
| `POST /api/mistake` → **404**；评分答错不自动记错题；`core/study.add_mistake` 无任何前端入口 | Lead p2 实测 + `dashboard.py` 路由表 |
| 笔记空态说"点知识点可以【记入笔记】"，但**数据库知识点详情弹窗没有该按钮**（只有导图产物节点窗口里才有） | Lead 浏览器交互复核（截图 11） |
| **AI 整理只写 `logs/knowledge/*.json`，不写数据库**；列表/复习队列只读数据库；真实站点有 7 份整理产物但 `knowledge_points` = 0 | `core/kp_build.py:27`、真实站点 `/api/kps`、`/api/queue` |

**影响**：三个角色都得出"这只是一个只读资料库"。对学霸=无法长期使用；对保研=无法建立可追踪计划；对突击=无法开始背。

### P0-B 检索召回/排序不可信（三方共识，且与源码审计缺口对应）

- 统一问题让 AI 说"资料里没有分类表"，实际 p.5《镇静催眠药分类》存在（`chunk 1382`，P2/P3 均给出实证）；
- 搜"苯二氮卓类 作用机制" top1 = 巴比妥类 p.29；目标 p.16/p.18 不在前 8；
- 对比题漏掉 p.18"BDZ 增加 Cl⁻ 通道开放频率"；
- 原因线索：`core/search.py` 重建版少 13 个函数、`expand_neighbors`/`expand_continuations` 被大幅简化（见 `docs/audit-2026-10-18/gap-report.md` §5.2）。
- **风险**：考前学生分不清对错 → 背错药，比"没有功能"更危险。

### P0-C 掌握度数据口径不一致（Lead 复现）

- `/api/kps`、`/api/graph` 返回原始 `mastery` 列（0.0）；
- `/api/kp?id=`、`/api/stats` 用 `compute_mastery()`（0.1144 / 0.3246）；
- 后果：知识点列表 0%、图谱节点全红、按掌握度排序失效、评分 toast 13% 与列表 0% 同屏矛盾。

### P0-D 空态与文案：循环指路 / 死链 / 开发者术语外泄

- 空态循环：总览"先去复习页"→复习页"先去知识点"→知识点页"先整理课件"→整理页"先入库课件"（实际已入库）；
- 死链：笔记/错题空态指向不存在的按钮；"批量整理"把"缺少结构产物"误报成"先入库课件"；
- 开发者术语外泄：`logs/knowledge/<doc_id>-末级知识点总结.json`、`tools/terms_build.py --doc <id>`、"卡 C-0058/0052"、
  "抗上下文刷新的长期记忆"等直接出现在学生可见页面（知识点页整屏都是）。

### P0-E 没有"学生管理"层：目标 / 考试 / 冲刺 / 进步

- 全站没有：考试倒计时、课程目标、保研线/绩点目标、周计划、进步趋势、连续学习天数；
- 复习页两套系统并存（知识点 SM-2 队列 + 课件 1/3/7/16/35 天月历）且互不写入，空态是"今天没有到期的复习 🎉"（学生：我明明还有没学过的）；
- 结果：P2 无法回答"还差多少分/这周有没有进步"；P3 无法回答"还剩几天/还要背多少"。

### P1-F 排版 / 信息架构 / 移动端（量化）

| 问题 | 量化证据 |
|---|---|
| 资料页主任务下沉 | 首屏 3420 字、整页高 3168px、123 个按钮；已入库列表在 y≈2364px（P1/P2/P3 一致） |
| 知识点页工程说明书 | 空态 1504 字开发者说明，无一个可点主按钮 |
| 字号层级倒挂/偏小 | 正文 14px/23.1px；卡片标题 13px（**小于正文**）；h1 17px；`.small` 12px |
| 对比度 | 正文 15.54:1 优秀；卡片/背景仅 **1.09:1**（只靠 1px 边框）；无浅色主题 |
| 行宽 | main max-width 1150px → 中文 ≈90 字/行（建议 ≤60） |
| 移动端 | 390 宽资料页 `scrollWidth=788`（**2.03 倍横向溢出**）；首屏 autofocus 滚动 396px；顶栏/表格不响应 |
| Markdown 渲染 | AI 回答里的表格显示为裸 `| 药名 |` 管道符 |
| 图谱 | 节点文字溢出小框、无缩放/筛选、无连边感 |
| 课件标题脏数据 | "3. 具有神经节阻断作用和促进组胺释放作用。" 被当作课件标题 |

### P1-G 复习体验细节（学霸/保研共识）

- 一条复习 = 3 次点击 + 2 次重渲染，无 1–5 快捷键、无"下一张"、评完关模态；
- 复习历史里"题目"列恒为"—"，无法复盘当时怎么答的；
- 掌握度涨到多少算"会"没有解释（首评后 13%，学生不知道目标线）；
- 月历统计出现"已完成 undefined"（数据拼接 bug）。

## 9. 建议的下一步（如果要继续改）

1. **先修 3 个"学生走不通"的 P0**：P0-1（知识点写入闭环，含产物一键入库）、P0-2（错题闭环）、P0-3（掌握度口径）；预计 2–3 天，即可把三份报告的"3–5 分"拉到 6–7 分。

3. **检索质量单独立项**：先做 P0-5 的规则级修复 + 10 题回归集（1–2 天）；若要彻底恢复 `search.py` 原版能力，再评估用救援工具链做 LLM 辅助反编译（约 ¥0.3 + 人工核对，需另行批准）。
4. **排版与移动端**可以在修 P0 时顺手做（P0-4 文案清理 + P1-5 资料页重排 + P1-6 移动端），一次改完再让三个角色复测。
