# P2 保研边缘生 · 学习看板体验报告

> 评测对象：D:\study_agent 学习看板（隔离实例 p2 / http://127.0.0.1:8902）
> 评测人：大三药学「保研边缘生」角色（第一人称）
> 时间：2026-10-18 22:00 ~ 22:35（Asia/Shanghai）
> 一句话结论：**它现在帮不了我保研。** 它是一个「课件资料库 + 带出处的 AI 答疑 + 单点复习打分器」，
> 不是一个能告诉我「差多少分、补哪、有没有在进步」的学习系统；而且最关键的「建知识点 / 记错题」
> 两条路在我这个新库里都是断的。

## 1. 人设与目标（我是谁）

我是大三药学专业学生，GPA 3.6/4.0 左右，专业排名中上，**保研线就在我附近浮动**——上一学期差 0.02，
这一学期两门专业课（药理学、药物化学方向）要提分。我每天在算「还差多少分」，偶尔emo，但更多是焦虑地刷题。

我平时怎么学习：微信收藏夹 + 纸质笔记 + 考前突击。Notion 我下过三次，每次都在「建数据库」那步放弃。
所以我需要的不是「强大的知识管理工具」，而是**打开就知道今天该学什么、学完能看到自己变强了一点**的东西。

我的目标拆开是四个问题：
1. **短板在哪？**（哪一章、哪个知识点总是错）
2. **我现在最该学什么？**（今天/这周的任务清单，不要我自己安排）
3. **我有没有在进步？**（数字/趋势，能拿去跟自己交代）
4. **离保研线还差多少？**（目标管理：分数、倒计时、课程目标）

### J4 AI 问答（全站最好用 · 3 动作 / 6.89 秒 / 1 次调用）

### 量化（1440×900，`result.styles` / 截图 / styles.json；原始值见 `evidence/numbers.md` §7）

| 次要文字对比度 | 6.84:1（card 上） | ✅ 过 AA，接近 AAA |
| 红色警示 5.19:1 | ✅ 过 AA | |
| 内容容器 | `main max-width:1150px`，padding 24 | ❌ 中文行宽 ≈1100px ≈ 84~91 字/行（建议 30~45 字/行） |
| 资料页首屏 | 3420 可见字 / 页面高 3168px / 504 节点 | ❌ 信息过载 |
| 遗忘曲线空月历 | 占屏高 ~500px，7×6 大格子 | ❌ 空态最显眼的是一大块空白 |

### 具体问题（3 条）

1. **标题比正文小、比正文淡**：所有卡片标题都是 13px 灰字（#9AA3B2），正文 14px 白字（#E6E9EF）。
   扫一眼「总览」「资料」「知识点」时，我的眼睛先看到正文噪音，标题反而像标签——找「这一块是干嘛的」很费劲。
2. **行宽没人管**：`main` 最大 1150px，减去 padding 后中文正文一行 ≈90 字，资料页的长解释横跨整个屏幕。
   我读两行就串行；这是「看不下去」而不是「看不懂」。
3. **空态占据视觉中心**：复习页在没有任何到期项时，最显眼的是 500px 高的空月历；我的第一感受不是「可以休息」，
   而是「这么多格子我是不是漏了什么」。空态应该给一个**主行动按钮**，而不是一块更大的空白。

### 做得好的地方（3 条）

1. **暗色主题对比度扎实**：正文 14.3:1、次要 6.84:1，晚上看白字不刺眼；米色/蓝色/红色三色徽章也不花。
2. **数据卡片的数字强调**：总览 26px 大数字 + 12px 灰色副标题，一眼能扫到「知识点 2 / 今日已复习 2 次」这种变化。
3. **出处条目的三级引用样式**（文档 › 章节 › 页码）在检索、问答、知识点出处里统一，配色克制，
   点开还有「命中」高亮——这是全站最让我信任的视觉设计。

## 6. 目标达成度总评（5 维 0~10）

| 维度 | 分 | 一句理由 |
|---|---|---|
| 目标匹配（能帮我保研吗） | **3** | 没有目标/分数/倒计时/课程目标，无法回答「还差多少分」；只能算辅助查资料 |
| 信息架构 | **3** | 8 个页签平铺无主次；资料/知识点两页是运维控制台；空态把人导到不存在的入口 |
| 学习效率 | **4** | 检索和 AI 问答很快（<7s 带出处），但「从 0 建立可复习的知识点」和「记错题」两步卡死，30 分钟得不到可追踪学习 |
| 可信度 | **4** | 出处纪律和"资料没有就说没有"很赞；但同一知识点掌握度 0%/11%/13% 三处不一致、月历显示 undefined，数字不敢信 |
| 整体推荐 | **3** | 现在适合当「课件资料检索 + 答疑工具」，不适合当「复习提分系统」；修好 P0 后潜力很大 |

**它现在能不能帮我实现目标（拿到保研资格）？——不能。**
它能帮我：快速查课件原文、问带出处的题、看哪个知识点分最低、按课件节奏排一个复习日历。
它不能帮我：知道保研线差多少、建自己的知识清单、记录并复盘错题、看见「这周比上周强」。
对一个每天算分、需要正反馈的人来说，用它的收益（查资料）远小于它的困惑（三个 0%、死路空态）。

## 7. 最帮我的 3 个功能 / 最劝退的 3 个问题

**最帮我的 3 个**
1. **AI 带出处答疑**：6.9s 给出结构化回答 + 13 个可点出处 + 诚实说资料里没有。这比问同学快，也比百度可信。
2. **课件大纲 + 检索出处**：2 步看到一份课件 39 行结构，检索结果带「文档›章节›页码」，复习时能立刻定位回原文。
3. **知识点详情的四格 + 0~5 中文评分**：掌握度/间隔/已复习/下次复习一屏说清，评分选项是「答错/勉强/正确」而不是裸数字，好懂。

**最劝退的 3 个问题**
1. **新用户第一条路是死路**：总览→复习→知识点→批量整理→「没有可整理的课件（先入库课件）」，可资料明明已入库 9 份；
   而手工新建知识点入口被删了。**我 3 步内就被劝退了。**
2. **错题本永远空**：答错了不记、没按钮、没接口，空态还骗我「复习答错时让助手记录，或在知识点详情里添加」。
   对我这种「靠错题提分」的人来说，这是最想要的功能够不着。
3. **进步看不见，数字打架**：列表 0%、详情 13%、图谱 0%；复习历史没有题目只有「—」；没有趋势/周报/目标。
   焦虑的人最怕「我学了吗？好像学了，又好像没学」。

### P0（先修，否则新用户走不通）

**P0-1 恢复「手工新建知识点」入口**（交互）
- 问题：知识点页空态只有批量整理/名词解释/导图三张运维卡，没有任何手工新建入口；后端 `POST /api/kp` 还在但没有前端调用方。
- 建议：空态顶部加一张「＋ 新建知识点」卡（名称/科目/一句话/可选出处），并在知识点列表右上角常驻同一按钮；批量整理降为第二入口。
- 验收：新库 0 知识点时，从任意页 ≤2 步进入表单，保存后知识点立即出现在「复习」页的到期队列里（脚本可验：空库→点新建→填名称→保存→`/api/queue` 长度 +1）。

**P0-2 修复错题闭环**（功能）
- 问题：`POST /api/mistake` 404；复习答错不写错题；错题空态指向不存在的「知识点详情里添加」；`core/study.py::add_mistake`（含自动降级）没有任何入口。
- 建议：① 在评分面板加「记下这道错题」（答错时可自动弹表单，题面/我的答案/正确答案/错因四格）；② 新增 `POST /api/mistake` 调 `study.add_mistake`；③ 复习答错（0~2 分）默认自动建一条「未解决」错题并 toast 告知，可撤销。
- 验收：评 2 分后错题本 +1、该知识点间隔归零；错题页能看到题面/错因/知识点；`POST /api/mistake` 返回 200。

**P0-3 统一掌握度口径**（数据/可信度）
- 问题：`/api/kps` 与 `/api/graph` 读库里原始 `mastery` 列（恒 0），`/api/kp?id=` 与 `/api/stats` 用 `compute_mastery()`（11%/13%）→ 同一知识点三处不一致。
- 建议：`api_kps` 与 `api_graph` 都改成 `study.compute_mastery(row)`；若性能敏感，单列一个物化列并在评分后更新。
- 验收：同一知识点在 列表 / 详情 / 图谱 / 总览 四处同时读取，掌握度差值 ≤1%（脚本对 4 个接口同 kp 断言）。

**P0-4 修空态与死链文案**（交互）
- 问题：笔记空态说「在知识点页点开任一知识点可以【记入笔记】」、错题空态说「在知识点详情里添加」——两处按钮都不存在；总览把「去复习页」当第一步，复习页又把我推回知识点。
- 建议：空态文案必须指向**当前真实存在的控件**；每个空态给一个可点的主按钮（新建知识点 / 写第一条笔记 / 记一道错题）。改文案前先跑一遍「空态链路真值测试」。
- 验收：新用户从总览开始，按每个空态提示点击，每一步都能到达目标控件（3 条链路自动化断言，无死链）。

**P0-5 批量整理在「无结构产物」时给自助修复入口**（功能/文案）
- 问题：本实例 9 份课件已入库，但整理弹窗说「没有可整理的课件：先入库课件」，与资料页矛盾；真实原因是缺 `logs/outline`（页面又写「不需要入库导图」）。
- 建议：区分「未入库」与「已入库但无结构产物」；后者给一个「生成结构 / 重建」按钮并说明耗时费用；不要用「先入库课件」这种错误归因。
- 验收：删掉 `logs/outline` 后打开弹窗，出现 1 个可点的「生成结构」按钮，点击后清单从 0 份变为 9 份。

**P0-6 加最小目标管理**（功能）
- 问题：全站没有保研/绩点/课程目标/考试倒计时，设置页只有四条 AI 管线配置。
- 建议：新增「目标」轻量面板：目标类型（保研线/单科 85/考试日）、目标值、当前值、剩余天数；总览顶部显示进度环（如「距药理学期末 46 天 · 目标 85，当前估 78」）+ 本周最小复习量（如 20 张知识点卡）。
- 验收：可设 2 个目标并在总览看到进度环与剩余天数；刷新后保留。

### P1（明显影响体验/效率）

**P1-1 进步可视化（趋势卡）**（功能）
- 问题：最薄弱列表只给当前值，没有趋势；我无法回答「这周比上周强吗」。
- 建议：总览加「最近 7/30 天」小卡：复习次数、覆盖知识点数（掌握度≥60%）、错题解决数、连续学习天数；数据全部来自现有 reviews/mistakes 表；再给「本周 vs 上周」一句人话结论。
- 验收：连续 3 天复习后趋势卡有 3 个数据点且随评分变化；开启第 4 天出现「比上周多复习 2 次」这类结论。

**P1-2 检索排序与分组**（算法）
- 问题：搜「苯二氮卓类 作用机制」top1 是巴比妥类，top4-8 全是米氮平；目标页 p.16/p.18 不在前 8。
- 建议：hybrid 里降低「作用机制」这种通用词权重、提高章节/标题命中和同文档聚集；结果按「课件/章节」分组折叠，显示「同一章节还有 N 条」。
- 验收：同一查询前 3 条全部来自「镇静催眠抗焦虑药 > 第一节苯二氮卓类」；2 首条 cite 页号在 p.14-p.18 之间。

**P1-3 AI 引用召回质量**（功能）
- 问题：课件 p.5 有「镇静催眠药分类」块（chunk 1382），AI 却回答「没有找到按化学结构分类的完整分类表」；引用浮窗泄漏「logs/figure_desc/」。
- 建议：把「分类/结构/概念」类块设为高优先候选；浮窗里把技术原因翻译成人话（「本页没有配图，可看原文/上下文」）。
- 验收：同一问题答案引用 p.5 并展示三类分法；引用浮窗不出现路径/日志术语（grep 断言）。

**P1-4 复习历史带上题目与答案**（功能/交互）
- 问题：复习历史只有「评分 4 / 题目 —」，学生复盘时想不起自己当时答了什么。
- 建议：评分前弹一个极简「自测卡」：显示问题（来自知识点名称/摘要）+ 可选的「我答的 / 正确答案」，允许跳过；历史表显示题面首 20 字 + 对错色。
- 验收：评分后复习历史「题目」列不再是「—」；展开能看到我的答案与正确答案。

**P1-5 两套复习系统合并成「接下来该做什么」**（交互/信息架构）
- 问题：复习页同时有知识点级 SM-2 队列和课件级 1/3/7/16/35 月历，两个粒度互不写入；且队列空态是「没有到期的复习 🎉」，我明明还有没学过的知识点。
- 建议：复习页顶部加「接下来 7 天」合并清单：今天（到期知识点 N + 课件轮次 M）/ 明天 / 本周，按逾期和掌握度排序，给「开始」按钮；月历降为第二层。
- 验收：打开复习页 5 秒内看到「今天/明天/本周」三行任务，且每行可点进具体知识点/课件。

**P1-6 资料页降噪**（🎨 排版/交互）
- 问题：资料页首屏 3420 字、页面 3168px 高，一半是 multipart/645MB/fail to fetch/logs 这类开发者说明。
- 建议：首屏只留 3 个动作（本机路径导入 / 拖拽 / 分享包）+ 已入库列表；把「为什么这样设计」「计费/OCR 说明」折叠进「说明 ▸」，默认收起。
- 验收：资料页首屏可见文字 ≤1700 字（-50%），三个主动作在首屏无滚动可见；折叠区默认收起。

**P1-7 结构层级与行宽**（🎨 排版）
- 问题：卡片标题 13px/灰 < 正文 14px/白（层级倒挂）；main max-width 1150px 导致中文行宽 ≈90 字/行；表格 12~13px、徽章 11px 偏小。
- 建议：卡片标题 15~16px 且用主文字色（#E6E9EF）；正文列限宽（内容区 ≤900px，表格可全宽）；`th` 12→13px、badge 11→12px；行高保持 1.6~1.7。
- 验收：1440 宽下正文行宽 ≤900px（CJK ≤60 字/行）；所有卡片标题字号 > 正文字号；用 styles.json 断言。

### P2（打磨）

**P2-1 空状态更有人味、更好行动**（🎨 排版/交互）
- 问题：复习页空态 = 巨空月历 + 「🎉」；笔记/错题空态长句技术解释；对焦虑学生「空」等于「我是不是漏了什么」。
- 建议：无计划时把月历折叠为一行「还没有复习计划 → 把当前课件加入计划」；空态统一成「一句人话 + 一个主按钮」；对「最薄弱/遗忘」加 tooltip（遗忘=复习时忘记的次数，不是扣分）。
- 验收：新用户首屏与复习页不存在超过 1/3 屏高的空白区域；每个空态至少 1 个主行动按钮。

**P2-2 给「掌握度」一个可理解的解释与目标线**（交互文案）
- 问题：答对一次只有 13%，没有说明怎么涨、涨到多少算会。
- 建议：掌握度旁加「i」：说明 = 记忆强度（间隔越长越高），并给「60% 算过关」的目标线；首次正确后显示「+13%，距过关还差 47%」。
- 验收：掌握度旁有 i 提示与阈值刻度；首次评分后 toast 带增量（+N%）。

**P2-3 笔记支持 Markdown 或至少排版清洗**（排版）
- 问题：`**一句话**`、`1.` 原样显示。
- 建议：至少支持粗体/列表/标题的轻量渲染（仍用 esc + 白名单），或在输入框提示「纯文本」。
- 验收：写含 `**粗体**` 与 `1.` 的笔记，详情里渲染为粗体与有序列表。

**P2-4 设置页分「学习设置」与「模型设置」**（信息架构）
- 问题：设置中心全是 AI 管线密钥/提示词；学生找不到提醒/目标/字体。
- 建议：设置分两队：学习（目标/每日提醒/字号/主题）与模型（现有内容，收进「高级」）。
- 验收：设置打开后默认显示学习设置，模型配置在「高级」二级页。

**P2-5 多学科加跨科总览**（功能）
- 问题：切到第二个学科后看不到「两门课合计今天要干什么」；每科从 0 开始。
- 建议：总览加「全部学科今天」聚合行（每科到期数 + 最近学习时间），允许「课程目标」挂在学科上。
- 验收：切到任意学科，总览顶部显示两门课的今日到期与目标进度。
