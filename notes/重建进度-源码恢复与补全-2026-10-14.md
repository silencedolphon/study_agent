残缺模块的恢复版来自**不同时间点**，判断某个片段属于哪一版，可以拿 `core/ingest.py` 当标尺：
- 恢复版 `ingest.py` = **1173 行**，而第一轮恢复（旧）是 **1041 行** ⇒ 1173 行这版**含 `ingest_file(mode=...)` 教材专线**（卡 C-0088 引入）
- 所以恢复版里凡是"与教材专线相邻"的代码，都属于 **≥ C-0088（2026-10-13）** 的时间点
- 反之 `core/study.py` 只有 487 行 ⇒ 它取到的是**较早**的会话片段

### 2.2 最完整的文件在 `project/`，不在 `_需要人工补充/`
`最终报告.md` §三 列 `tools/dashboard.py | 12403`，而 `最终恢复清单.md` 列 8917 —— **以 `project/study_agent/` 下的实际文件为准**（12403 那版）。`_需要人工补充/` 是副本。

### 2.3 v1.1 包是"完整时间点"的源码
`StudyDashboard-v1.1-win64.zip`（约 140MB）是 PyInstaller **onedir** 产物，内含：

- `logs\knowledge\` 的 4 份**业务提示词**（可直接补回）

**用法**：反编译 `.pyc` → 得到 v1.1（≈ C-0086）时刻的完整源码 → 与恢复版**并集**；
再用下面的"功能清单"把 C-0086 之后的新功能补回来。

### 2.4 反编译工具选择（Python 版本决定）
- 先跑 `venv\Scripts\python.exe -V` 看版本：
  - **3.11 / 3.12** → 用 `pycdc`（Decompyle++，支持 3.11~3.13）：`pycdc xxx.pyc > xxx.py`
  - **3.9 / 3.10** → `pip install decompyle3` 或 `uncompyle6`
  - 反编译失败时退一步：`pip install xdis`，用 `xdis` 读常量表与函数名列表，**人工按恢复版拼接**（恢复版已有 12403 行，缺的是少数片段）
- **`.pyc` 里保留函数名、类名、字符串常量、行号表** ⇒ 即使反编译失败，也能靠"常量与函数名清单"对齐恢复版的缺口位置
