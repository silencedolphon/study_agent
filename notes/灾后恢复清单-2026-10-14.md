## 4. 六条避坑判据（都是这轮重建踩出来的）

1. **`.ps1` / `.cmd` 必须纯 ASCII** —— Windows 用 OEM 代码页解析，中文会被逐字节误解码（报"数组索引表达式丢失"）。
2. **f-string 里不能放反斜杠**（如 `ESCAPE '\\'`）—— Python ≤3.11 是 SyntaxError。
3. **`Measure-Object -Line` 不数空行**；`| Select-Object -First N` 会让 `$LASTEXITCODE` 变 **-1**。
4. **不要重跑 `recover-step1.ps1`** —— 它会用恢复源覆盖已修好的
   `outline.py` / `study.py` / `study.py(tools)` / `dashboard.py` / `kp_batch.py`。
5. **`dashboard.py` 不能用旧 HTML 整块替换** —— 恢复版的 HTML 比 v1.1 新
   （`--accent:#5e6ad2` vs `#5b9dff`），替换会回退 C-0096 之后的前端改动。正确做法是**只删那个错位块**。
6. **DSH 本机执行器坏了**：`spawn C:\WINDOWS\System32\WindowsPowerShell\v1.0\powershell.exe ENOENT`
   ⇒ AI 会话里跑不了命令（子会话同样），**命令必须由人执行**；修法：启用 Windows PowerShell 5.1 组件，
   或装 PowerShell 7 并让 DSH 指向 `pwsh.exe`。
